# 💡 LUZ VIVA
### Plataforma web de iluminação pública e participação cidadã

🔗 **Acesse a plataforma:** [LUZ VIVA – GitHub Pages](https://luana-vigolo.github.io/LuzVivaGS/)

## 📌 Sobre o projeto

O **LUZ VIVA** é uma plataforma web desenvolvida com o objetivo de facilitar a identificação e o registro de problemas relacionados à iluminação pública.

A proposta é incentivar a participação cidadã, permitindo que moradores e pessoas que utilizam espaços públicos registrem pontos com iluminação inadequada e consultem as ocorrências cadastradas.

## ✨ Funcionalidades

- **Apresentação do projeto:** informações sobre o problema da iluminação pública e a proposta da plataforma.
- **Formulário de ocorrências:** cadastro de problemas com informações sobre localização, tipo de local, problema identificado e índice de luminosidade.
- **Validação de dados:** verificação dos campos obrigatórios e dos valores informados antes do cadastro.
- **Confirmação de cadastro:** possibilidade de conferir os dados antes de registrar uma ocorrência.
- **Classificação de luminosidade:** identificação dos níveis como crítica, atenção ou adequada.
- **Listagem de ocorrências:** exibição dos relatos cadastrados na própria página.
- **Galeria de imagens:** apresentação de exemplos de locais com diferentes condições de iluminação.

## 🛠️ Tecnologias utilizadas

- **HTML:** estruturação do conteúdo da plataforma.
- **CSS:** estilização, organização dos elementos e responsividade.
- **JavaScript:** validação de formulários, classificação de luminosidade, cadastro de ocorrências e interações da página.

## 🎯 Objetivos

- Facilitar a comunicação de problemas relacionados à iluminação pública.
- Reunir informações sobre pontos com iluminação inadequada.
- Incentivar a participação dos cidadãos.
- Contribuir para a identificação de locais que precisam de maior atenção.
